# SmartExpense — Smart Expense Tracker

A responsive, JavaScript-first expense tracker built with HTML, Tailwind CSS and JavaScript.

## Features
- Dynamic dashboard with balance, income, expenses and savings
- Add/delete income and expense transactions
- LocalStorage persistence
- Search and filter transactions
- Category budgets with progress indicators
- Savings goals
- Spending analytics and charts
- Smart spending insight
- 2D CSS animations and subtle 3D hover effects
- Responsive layouts for mobile, tablet, desktop and large TV screens
- Reduced-motion support
- No framework; JavaScript handles the application logic

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For best development experience, use VS Code + Live Server.
4. Internet is required for the Tailwind CDN and Chart.js CDN in this starter version.

## Tech
HTML5 · Tailwind CSS · Vanilla JavaScript · Chart.js · LocalStorage

## Project structure
- `index.html` — application UI
- `js/app.js` — state, CRUD, rendering, charts, analytics, interactions
